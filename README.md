## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of web technologies (optional for viewing)

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mfree-Ioah67/web-portfolio.git
   cd web-portfolio
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your preferred browser
   # Or use a local server for development
   python -m http.server 8000
   # Navigate to http://localhost:8000
   ```

3. **Development**
   - Edit HTML in `index.html`
   - Modify styles in `styles/` directory
   - Update JavaScript in `scripts/` directory

## 🎨 Customization

### Color Scheme
The portfolio uses CSS custom properties for easy theming:

```css
:root {
  --primary-color: #00ff41;    /* Matrix green */
  --secondary-color: #0066cc;  /* Blue accents */
  --accent-color: #ff0040;     /* Red highlights */
  --bg-dark: #0a0a0a;         /* Dark background */
  --text-secondary: #ffffff;   /* White text */
}
```

### Terminal Content
Update terminal animations in `scripts/terminal.js`:

```javascript
// Modify typing text arrays
const commands = [
  'initiate secure session...',
  'loading profile: your@domain.com',
  // Add your custom commands
];
```
